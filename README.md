# Big-Data-in-the-Cloud
Food price forecasting and country comparison for Djibouti and Haiti using Azure.
# Big Data in the Cloud

## Exam Case
Contract Country: Djibouti  
Comparison Country: Haiti

## Objective
Build a cloud-based solution to:
- ingest and structure global food price data
- compare food price developments between Djibouti and Haiti
- forecast available commodity prices
- analyse possible correlations in price fluctuations
- present results to government stakeholders

## Proposed Architecture
- Azure Blob Storage
- Azure Data Factory
- Azure SQL Database
- Azure Databricks
- Azure Monitor / Logic Apps
- Power BI Desktop

## Repository Structure
- `REQUIREMENTS.md` – requirements engineering
